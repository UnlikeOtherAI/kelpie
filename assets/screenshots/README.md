# README screenshots

- `macos-start-page.png`: native macOS browser capture from the [start-page change](https://github.com/UnlikeOtherAI/kelpie/pull/186), shipped in macOS 0.2.4. Captured for the [3D controls change](https://github.com/UnlikeOtherAI/kelpie/pull/185); the [original image](https://github.com/UnlikeOtherAI/kelpie/releases/download/release/2026-11-09.1/desktop-after.png) is attached to that release candidate. This is the inspector content, without native window chrome.

When replacing a screenshot, capture the actual interface, check that it contains
no private browsing data, and update its description and source here.
